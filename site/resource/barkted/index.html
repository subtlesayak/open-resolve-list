Subtitles, transcription, dialogue cleanup, and automatic editing · Subtitle tool

BarkTed

By TeddieWang

Local Whisper transcription and subtitle translation for Apple Silicon Macs running Resolve Studio 21+. Installer bundles the runtime and transcription model. Optional TranslateGemma translation runs locally; API translation sends subtitle text to the chosen provider and may incur charges. Intel Macs, Windows and Linux are not supported by this installer.
