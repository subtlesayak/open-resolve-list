Fusion, motion graphics, visual effects, and package management · OFX plugin

vm-cursor

By zirmila

Windows screen-capture companion and OFX effect for cursor-following zooms, highlights and keystroke overlays. The plugin requires NVIDIA CUDA; capture can use other hardware. Creator reports Resolve 21 Studio testing but only assumes Free support. Portrait/letterboxed recordings have known positioning limitations.
