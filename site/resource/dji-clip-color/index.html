dji-clip-color

By erik-sutton95

Identifies DJI camera profiles from clip metadata and assigns Resolve clip colors for D-Log, D-Log 2, D-Log M and HLG. It organizes media rather than applying a color transform. Windows requires 64-bit Python 3. Python scripting requires Studio in Resolve 21.1.
