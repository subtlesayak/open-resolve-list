  • platforms — Source documented

    Linux x86-64 Resolve Studio. Provider build labels are not converted into a supported Resolve version range. GPU/video codec support is unchanged.

  • requirements — Source documented
    Original source · checked 2026-11-21

    Experimental AAC import/playback and AAC-LC export bridge for Resolve Studio on Linux x86-64. Uses validated in-memory hooks; unknown layouts stay inactive. The provider reports selected Studio builds, with other profiles, multichannel and sample-accurate delay still needing validation. Replaces the deprecated standalone FDK encoder; not production-qualified native codec support.
