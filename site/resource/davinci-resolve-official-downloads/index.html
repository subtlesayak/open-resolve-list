Version history

  1. 21.0.4 → 21.1

    Media: editable pool fields, recursive/exact searches, geometry previews, timecode and marker batch edits, multicam dates and audio-track controls.

    Recorded 2026-09-08 · upstream date 2026-09-08

    • Media: editable pool fields, recursive/exact searches, geometry previews, timecode and marker batch edits, multicam dates and audio-track controls.
    • Photo: panel-driven RAW settings, sharpening and sidebar improvements, DNG lens corrections, sky replacement and live-view shortcuts.
    • Editing: inspector presets, expanded multicam controls, timeline comparison, richer markers, waveform display, trim and gap operations, adjustment-clip transitions, backup and playback refinements.
    • Fusion: Krokodove shapes/3D, OpenPBR materials, MultiText and OGraf controls, DRFX macro editing, tracking import, blend/alpha improvements and metadata variables.
    • Color: LUT/DCTL relinking, missing-DCTL overlays, additional camera transforms, panel controls and effect scaling.
    • General: newer hardware/media decoding, HTJ2K EXR output, caption exports, media-management reporting, archive options and PostgreSQL 18 Project Server.
    • Compatibility: Python/advanced scripting now needs Studio; projects opened in 21.1 cannot reopen in 20.3.2. Apple Silicon and macOS 15 are required on Mac.
    • Studio additionally brings native MCP/AI integration, expanded Python APIs, MultiMaster trims, deep rendering improvements, extra RAW formats and effects. Read the separate full edition notes for every change and requirement.
    Source changelog

  2. 21 (advertised product family) → 21.0.4

    Exact patch identified; proxy relinking, X-OCN formats and timeline scripting updates.

    Recorded 2026-09-07 · upstream date 2026-08-05

    • Proxy relinking now accepts mismatched formats.
    • Imported DRTs reconnect to matching nested clips already present.
    • Color-page filtering keeps the selected clip visible.
    • Older Affinity formats can be imported.
    • Sony FX-5 footage encoded as X-OCN is supported.
    • Scripts can retrieve the selected timeline clips.
    • Scripts can obtain a timeline object through its Media Pool entry.
    • Render-setting scripts gain controls for handles, extents and burn-ins.
    • Cached large timelines receive real-time playback fixes.
    • Media Pool Power Bin navigation is corrected.
    • Media management handles segment-clip suffixes correctly.
    • Edit Index sorting is corrected.
    • Pasting timecode no longer triggers the reported source-viewer audio problem.
    • Several speed-curve retiming problems are corrected.
    • Windows Fusion templates handle long paths correctly.
    • Burn-ins regain the missing marker-notes tag.
    • Decoding is corrected for affected DPX files.
    • Decoding is corrected for affected CR2 images.
    • Free-edition notes additionally report a Windows software H.264 decoding fix.
    • Additional reliability and speed improvements.
    Source changelog
