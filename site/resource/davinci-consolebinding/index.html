DaVinci-ConsoleBinding

By titasmallick

Windows XInput controller bindings for Resolve using PowerShell/C# keyboard and mouse automation. Supports configurable gamepad actions and limits input to the foreground Resolve window; no Resolve scripting bridge is required.
