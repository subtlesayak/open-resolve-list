Subtitles, transcription, dialogue cleanup, and automatic editing · Subtitle tool

tscaps

By francozanardi

Browser subtitle editor with local Whisper transcription, animated captions, SRT export and burned-in video export. Useful alongside Resolve through subtitle/media files; it does not create editable Fusion captions.
