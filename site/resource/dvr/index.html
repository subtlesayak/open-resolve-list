AI assistants, MCP servers, and ComfyUI integrations · MCP server

dvr

By mhadifilms

CLI, Python client and MCP interface for Resolve projects, timelines, media and grading operations, with structured JSON output. Requires Resolve Studio 18.5+ and Python 3.10+. Any connected AI assistant has separate processing and access terms.
