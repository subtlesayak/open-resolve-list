oside-resolve-mcp

By OSideMedia

MCP workflow that builds Resolve projects from JSON manifests and a user-supplied DRP template: bins, ordered timelines, markers, narration and CDL look data. Requires Resolve Studio; provider documents Studio 21.1 checks on macOS. Includes read-back acceptance checks, with no service account required for the local server.
