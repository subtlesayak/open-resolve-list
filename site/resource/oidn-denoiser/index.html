Oidn Denoiser

By Jacob Danell

Fusion Fuse for denoising ray-traced renders using Intel Open Image Denoise, optionally with albedo and normal passes. Current package bundles OIDN 2.5.1 and documents CPU/GPU processing on Windows, macOS Intel/Apple Silicon and Linux. Reactor version field is 2.0501; embedded changelog names the bundled OIDN release as 2.5.1.
