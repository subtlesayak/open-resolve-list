About Open Resolve List

A personal directory for finding DaVinci Resolve and Fusion tools, resources and the people who make them.

Why I made it

Useful Resolve resources are scattered across repositories, creator websites, stores and community threads. I built Open Resolve List to keep those links together and make it easier to find something for a particular workflow. It is a personal project hosted on GitHub Pages, with the catalogue and source records open on GitHub.

The directory covers free and paid plugins, Fusion tools, DCTLs, LUTs, PowerGrades, scripts, templates and workflow utilities. If you find it useful, you are welcome to use it, share it and report issues. Open Resolve List is independent and is not affiliated with Blackmagic Design.

Find tools and creators

Search the catalogue by tool name, creator, description or reviewed tags. Try a task such as film emulation or captions, then narrow the results by format, platform, Resolve edition/version, access and other recorded requirements. Search matches the catalogue text and tags; it does not generate answers or test compatibility.

Results start in alphabetical order. You can choose other sorts, compare similar tools side by side, export a comparison as CSV and copy a link to your filtered view. Resource pages bring together original links, requirements, evidence and available update references.

The creators directory includes tool makers, educators and training providers. Search or filter it by topic, then visit a creator page for their catalogue resources, channel and website. A separate Reactor package inventory credits the authors recorded in its manifests and sits outside the main catalogue.

If you use an AI assistant to find a match, share the repository link and describe your task, operating system, Resolve edition/version and budget. Ask it to follow the task guide and the machine-readable guidance, cite original sources and identify any unknown requirements.

Know what the evidence means

Source documented
A linked provider page or repository supports the named fact. It does not mean the tool was installed or tested.

Creator confirmed
A creator explicitly confirmed the named fact in an attributable source. A listing notification is not confirmation.

Community tested
A reviewed report records the exact host, platform, tool version, task, result and limitations.

Not established
The catalogue has no adequate evidence for that field. Unknown does not mean unsupported.

AI assists discovery and organization; sources, uncertainty and editorial review govern the data. Stars measure GitHub interest, not quality. Check each resource's source and requirements before choosing it. The catalogue does not claim complete coverage.

Updates and activity

The Updates page preserves catalogue additions and verified provider changes, with original release or changelog links where available. Individual resource pages retain their own update references. Catalogue releases group new providers/resources and updates to existing ones; website and documentation maintenance stays in Git history/tags without a catalogue release. You can subscribe to the release feed.

Update ages use days, weeks, months or years. Repository activity means a push; external dates identify their supporting release, devlog, installer or package record. † marks a date more than two years old, not proof of abandonment. Unknown means no supported date was established. A website-check date is never substituted for a product update date.

Contribute or correct a listing

Suggest a resource, confirm or correct your creation, or share a tested workflow. Include original source links and the exact setup when relevant. Creators can also request that a listing be removed.

Your browser and external services

Catalogue search and filtering run in your browser. Your setup choices and theme are saved on this device. Shared view links contain the search and selected filters, so check the URL before sharing it.

The footer requests an approximate page-view count from CountAPI (Miles Hilliard). Counts represent page loads, not unique people. That request uses a fixed public site identifier and sends no search text, filters, referrer or cookies; the service can receive your IP address. The last available count may be saved locally.

The Buy Me a Coffee button loads a third-party script and may request assets such as fonts from external services. Those requests are separate from catalogue search and are subject to the providers' own policies. Following creator, GitHub or support links takes you to those services.
