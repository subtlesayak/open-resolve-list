Fix choppy timeline playback

All workflows

Expected result

Find whether the slowdown comes from the editing mode, source media, or effects.

Setup

Pick a section that stutters in normal playback. Compare a clean clip with a clip that has effects, and watch the playback frame-rate indicator.

Steps

  1. Switch to Selection Mode before playback. One solved case came from Dynamic Trim mode, which changes playback behavior while trimming.
  2. Try Playback → Timeline Proxy Resolution → Half. This lightens timeline processing without creating proxy files or changing delivery resolution.
  3. If a clean clip still struggles, choose a proxy format and size in Project Settings → Master Settings. Generate Proxy Media for the clip from the Media Pool, choose Playback → Proxy Handling → Prefer Proxies, and replay the same section.
  4. If clean clips play smoothly but graded or Fusion sections do not, try Playback → Render Cache → Smart. Wait for the cache to build, then compare playback.
  5. Before delivery, switch back to the camera originals and check which media and resolution the Deliver settings will use.

Alternatives

  • Blackmagic Proxy Generator

    Use a watch folder to generate proxies before editing when you ingest camera originals in batches.

    Original source

Limitations

Proxy files and render cache use disk space. Proxies mainly help when source decoding is the bottleneck. Heavy effects may still need caching. Menu wording varies by Resolve version.
