Remove black bars from vertical exports

All workflows

Expected result

Match the timeline and export to 9:16, then reframe clips that leave black bars.

Setup

Use this for a portrait export with unwanted bars. Keep a copy of the original edit if you also need a horizontal version.

Steps

  1. Duplicate the timeline in the Media Pool. Right-click the copy and open Timelines → Timeline Settings.
  2. Turn off Use Project Settings. In Format, set the timeline to 1080 × 1920. Use vertical resolution swaps the width and height, so confirm the displayed dimensions.
  3. Check the timeline viewer. For clips with a different aspect ratio, choose Scale full frame with crop under Mismatched resolution to fill the portrait frame. Use Zoom and Position in the Inspector to keep the subject in view.
  4. On Deliver, confirm the export is 1080 × 1920 and uses the timeline framing. Render a short range that includes the clips you reframed.
  5. Play the test file outside Resolve. If the file fills the portrait frame and bars appear only after uploading, check the destination’s crop or fit setting.

Alternatives

  • Fit the whole image

    Choose Scale entire image to fit when the whole source frame matters. Use a deliberate background behind the clip to fill the remaining space.

    Original source

Limitations

Filling a portrait frame with landscape footage crops the sides. Bars already baked into a source file need per-clip cropping or a clean source.
