Create automatic subtitles

All workflows

Expected result

A reviewed subtitle file or styled subtitle timeline.

Setup

AutoSubs and media containing clear speech. Check the current installer and Resolve integration requirements before use.

Steps

  1. Open an audio or video file in AutoSubs standalone mode.
  2. Choose a transcription model and language, then transcribe.
  3. Review the transcript, speakers and timing; export SRT or text.
  4. For styled Resolve output, follow the provider’s Resolve integration guide and send the reviewed subtitles to Resolve.

Tools and references

Alternatives

  • Resolve-OpenCaptions

    Style an existing subtitle file as editable Text+ clips. This covers subtitle presentation; it does not establish automatic speech recognition.

Limitations

Model downloads need a connection. Check model licenses and transcription accuracy. The provider excludes the Mac App Store Resolve build. Not installation tested by this catalogue.
