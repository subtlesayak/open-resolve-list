Restore audio in a silent export

All workflows

Expected result

Render a test clip with the intended stereo mix before exporting the full cut.

Setup

Use this for a stereo video that sounds right in Resolve but plays silently after export. Choose a short range with clearly audible dialogue or music.

Steps

  1. Play the range in Fairlight and watch the track meters and main stereo bus meter. If tracks move but the main bus stays silent, check track mutes, solos, and bus routing.
  2. On Deliver, choose Single Clip. Open the Audio tab and enable Export Audio.
  3. Set Output Track 1 to the stereo bus carrying your mix. In a default project this is commonly Bus 1 (Stereo). Use the name shown on the working Fairlight bus.
  4. Queue a new job for the short range. Play the file in a second player or import it into Resolve to check that it contains the intended audio.
  5. After the test passes, set the full range and add a job with the same verified audio settings.

Alternatives

  • Quick Export for a stereo cross-check

    Try Quick Export on a safe test timeline to check the stereo mix before comparing custom Deliver settings.

Limitations

Stems, surround, and channel-specific client specifications need their own routing and output settings. If Fairlight meters move but Resolve itself is silent, check Preferences → Video and Audio I/O for the monitoring device.
