Fix video importing as audio only

All workflows

Expected result

Identify an unsupported video codec or profile and convert a test clip before importing the rest.

Setup

Use this when an MP4 or MOV plays with picture in another app but appears as audio only in Resolve’s Media Pool. Keep the camera originals.

Steps

  1. Open Resolve → About DaVinci Resolve and note the version and edition. In Shutter Encoder, right-click a source file and choose File(s) information to check its video codec, bit depth, and chroma subsampling.
  2. Check Blackmagic’s codec list for your version and operating system. If the clip shows picture in the Media Pool and loses it only when added to the timeline, check video track targeting first.
  3. Convert one affected clip in Shutter Encoder to DNxHR HQX in a MOV container. Keep the source resolution and frame rate for this test and save the copy to a separate folder.
  4. Import the converted copy as a new clip. Check picture, audio channels, sync, and color in Resolve. Convert the remaining clips after the test passes.

Alternatives

  • Convert a smaller test copy with HandBrake

    The solved thread used H.264 in MP4. Try an 8-bit H.264 test copy if file size matters and the source can tolerate the compression and bit-depth reduction.

Limitations

Codec support varies by version, operating system, edition, and profile. DNxHR HQX takes substantially more disk space. Review timecode and metadata before replacing any media in an existing edit.
